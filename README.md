# Bartho — Assistente administrativo com IA para clínicas

Bartho é um projeto de Produto desenvolvido para investigar como um assistente conversacional com IA pode resolver jornadas administrativas de uma clínica de ponta a ponta.

O protótipo combina interpretação de linguagem natural com regras de negócio e execução determinística para realizar tarefas como consulta de disponibilidade, agendamento, remarcação, cancelamento e dúvidas administrativas.

## Sobre o projeto

O projeto foi estruturado como um case de Produto, passando por:

- definição do problema;
- formulação de hipótese;
- definição e priorização do MVP;
- construção do protótipo;
- definição de métricas;
- testes com usuários;
- análise dos resultados e aprendizados.

## Resultado do MVP

Em uma rodada exploratória com 20 participantes:

- **17 de 20** concluíram a jornada sem intervenção humana;
- **85%** de resolução autônoma observada.

Os testes também permitiram identificar limitações relacionadas principalmente à latência e à manutenção de contexto em interações mais complexas.
